# .config/scruth_env/manual

This directory contains artifacts related to manual configuration (i.e. that scruth-config doesn't handle or apply
automatically).

- `bettertouchtool` holds a manual export of BTT configuration, for manual import into new systems 

- `Scott.terminal` is a MacOS classic Terminal app profile that can be imported via its settings.  
It depends on the JetBrains Mono font that scruth-config should have installed (via brew) ahead of that.
